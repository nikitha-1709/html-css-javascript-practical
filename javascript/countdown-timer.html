Create a Countdown Timer

Description: A configurable countdown timer.

Working Implementation & Output

10 Seconds Remaining

Source Code

js-36.html 
function countdown(seconds) {
  const timer = setInterval(() => {
    seconds--;
    if (seconds <= 0) clearInterval(timer);
  }, 1000);
}
