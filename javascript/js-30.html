Create a form validation program

Description: Validates required fields, email format, and password length with error messaging.

Working Implementation & Output

Source Code

js-30.html 
function validateForm(name, email) {
  if (!name) return 'Name required';
  if (!email.includes('@')) return 'Invalid email';
  return 'Valid';
}
