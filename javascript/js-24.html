Create a button click event using JavaScript

Description: Demonstrates attaching click event listeners using addEventListener and handling user interaction.

Working Implementation & Output

Click the button to fire the click event listener.

Source Code

js-24.html 
const btn = document.getElementById('myBtn');
btn.addEventListener('click', () => {
  alert('Button clicked!');
});
