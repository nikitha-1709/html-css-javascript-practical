Create a program to show/hide an HTML element

Description: Demonstrates toggling element visibility using CSS display properties (none vs block).

Working Implementation & Output

Toggleable Notice: This card can be revealed or hidden by updating element.style.display.

Source Code

js-25.html 
function toggle() {
  const el = document.getElementById('box');
  el.style.display = (el.style.display === 'none') ? 'block' : 'none';
}
