Create a webpage demonstrating font properties and text formatting

Description: Demonstrates font-family, font-size, font-weight, font-style, line-height, text-align, text-transform, and letter-spacing.

Working Implementation & Visible Output

Georgia Serif Bold (font-weight: 700, font-size: 18px)

Monospace with 2px letter-spacing & uppercase transform

Italic font style with generous line-height (1.8) and justified alignment providing optimal editorial cadence.

Text with dashed underline decoration (text-decoration: underline dashed red).

Source Code

css-04.html 
.heading {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  font-size: 24px;
  font-weight: bold;
  text-transform: capitalize;
}
.body-text {
  font-size: 16px;
  line-height: 1.6;
  letter-spacing: 0.5px;
  text-align: justify;
}
