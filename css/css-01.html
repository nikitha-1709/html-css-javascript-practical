Create a webpage demonstrating inline, internal, and external CSS

Description: Demonstrates the three methods of attaching CSS styles to an HTML document and their cascading hierarchy.

Working Implementation & Visible Output

1. External CSS: Styled via ../assets/common.css (Global container, typography, reset).
2. Internal CSS: Scoped inside the page's <style> block.
3. Inline CSS: Applied directly on this tag via style="color:#991b1b; font-weight:bold;".

Source Code

css-01.html 
/* External: in styles.css */
body { font-family: sans-serif; }

/* Internal: in <style> tag */
.internal-box { background: #f0fdf4; padding: 12px; }

/* Inline: in HTML tag */
<div style="color: red; font-weight: bold;">Inline text</div>
