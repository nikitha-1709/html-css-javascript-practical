Create a webpage using different CSS selectors

Description: Demonstrates element, class, ID, universal, and grouping selectors.

Working Implementation & Visible Output

.class-selector

Selects elements having the class attribute.

#id-selector

Selects a single unique element with matching ID.

h4, p (Grouping)

Applies the same style rule to multiple selectors.

Source Code

css-02.html 
* { box-sizing: border-box; } /* Universal */
h1 { color: #1e293b; } /* Element */
.highlight { background-color: yellow; } /* Class */
#special-header { font-size: 24px; } /* ID */
h2, h3, p { margin-bottom: 8px; } /* Grouping */
