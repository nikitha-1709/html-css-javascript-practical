Write a program to find the sum and average of array elements

Description: Calculates total summation and arithmetic mean of array items.

Working Implementation & Output

Output.

Source Code

js-14.html 
function getSumAndAverage(arr) {
  const sum = arr.reduce((a, b) => a + b, 0);
  const avg = sum / arr.length;
  return { sum, avg };
}
