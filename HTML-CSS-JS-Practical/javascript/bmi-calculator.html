Create a BMI Calculator

Description: Calculates Body Mass Index from height and weight.

Working Implementation & Output

Select an operation to calculate.

Source Code

js-02.html 
function calculate(a, b, op) {
  switch(op) {
    case '+': return a + b;
    case '-': return a - b;
    case '*': return a * b;
    case '/': return b !== 0 ? a / b : 'Cannot divide by zero';
    case '%': return a % b;
  }
}
