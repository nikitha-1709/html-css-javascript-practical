Write a program to find the largest of three numbers

Description: Compares three numerical inputs using conditional logic to determine the maximum value.

Working Implementation & Output

Click button to compute.

Source Code

js-03.html 
function findLargest(a, b, c) {
  if (a >= b && a >= c) return a;
  else if (b >= a && b >= c) return b;
  else return c;
}
