Write a program to reverse a number

Description: Reverses the digits of an integer mathematically using division and modulo.

Working Implementation & Output

Reversed output will show here.

Source Code

js-10.html 
function reverseNumber(n) {
  let rev = 0;
  let num = Math.abs(n);
  while (num > 0) {
    rev = rev * 10 + (num % 10);
    num = Math.floor(num / 10);
  }
  return n < 0 ? -rev : rev;
}
