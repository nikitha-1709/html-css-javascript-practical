Write a program to find the least common multiple (LCM) of two numbers

Description: Computes LCM using formula: LCM(a, b) = (a * b) / GCD(a, b).

Working Implementation & Output

LCM output.

Source Code

js-50.html 
function lcm(a, b) {
  return Math.abs(a * b) / gcd(a, b);
}
