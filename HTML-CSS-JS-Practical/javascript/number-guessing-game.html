Create a Number Guessing Game

Description: Interactive random number guessing game with hints.

Working Implementation & Output

Guess a number between 1 and 100.

Source Code

js-29.html 
let secret = Math.floor(Math.random() * 100) + 1;
function guess(val) {
  if (val === secret) return 'Win!';
  return val < secret ? 'Too Low' : 'Too High';
}
