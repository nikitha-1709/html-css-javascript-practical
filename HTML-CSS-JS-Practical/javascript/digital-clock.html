Create a Digital Clock

Description: A real-time digital clock updating every second.

Working Implementation & Output

00:00:00 AM

Updates every 1000ms using setInterval.

Source Code

js-27.html 
function startClock() {
  setInterval(() => {
    const now = new Date();
    document.getElementById('clock').textContent = now.toLocaleTimeString();
  }, 1000);
}
