Demonstrate the CSS box model using margin, border, padding, and content

Description: Demonstrates the four concentric layers of the CSS Box Model: Margin (orange), Border (yellow), Padding (green), and Content (blue).

Working Implementation & Visible Output

MARGIN (External Spacing)
BORDER (4px Solid)
PADDING (Internal Spacing)
CONTENT (Width × Height)

Source Code

css-05.html 
.box {
  width: 300px;
  height: 150px;
  padding: 20px;       /* Green inner space */
  border: 4px solid #eab308; /* Yellow border */
  margin: 24px auto;   /* Orange outer space */
  box-sizing: content-box; /* Or border-box */
}
