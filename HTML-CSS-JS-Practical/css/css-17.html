Create a webpage demonstrating transitions and transformations

Description: Demonstrates transition timing functions with 2D transformations: scale, rotate, and translate.

Working Implementation & Visible Output

Hover Scale
Hover Rotate
Translate Y

Source Code

css-17.html 
.box-scale:hover { transform: scale(1.2); }
.box-rotate:hover { transform: rotate(45deg); }
.box-translate:hover { transform: translateY(-10px); }
.box { transition: transform 0.3s ease; }
