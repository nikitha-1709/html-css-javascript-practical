Create a webpage using CSS animations

Description: Demonstrates @keyframes animations with animation-duration, iteration-count, and alternate direction.

Working Implementation & Visible Output

Source Code

css-18.html 
@keyframes pulse {
  0% { transform: scale(0.8); }
  100% { transform: scale(1.2); }
}
.animated-circle {
  animation: pulse 1.5s infinite alternate ease-in-out;
}
