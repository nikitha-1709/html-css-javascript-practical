Create a webpage demonstrating CSS Grid layout

Description: Demonstrates grid-template-columns, grid-template-rows, gap, and grid-column span.

Working Implementation & Visible Output

Header Area (grid-column: span 3)

Source Code

css-15.html 
.grid-layout {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.grid-header, .grid-footer { grid-column: span 3; }
.grid-sidebar { grid-column: span 1; }
.grid-content { grid-column: span 2; }
