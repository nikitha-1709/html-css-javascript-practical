Create a responsive webpage using CSS media queries

Description: Demonstrates responsive viewport adaptation across Mobile (< 600px), Tablet (600px - 900px), and Desktop (> 900px) using @media rules.

Working Implementation & Visible Output

Current Viewport: Desktop / Wide Screen

Resize your browser window to observe live layout transformation.

Column 1

Adapts from 3 cols to 1 col on mobile devices.

Column 2

Fluid columns automatically re-wrap seamlessly.

Column 3

Zero horizontal scrollbar overflow guarantee.

Source Code

html-13.html 
/* Desktop Default */
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 20px;
}

/* Tablet Media Query */
@media (max-width: 900px) {
  .grid-container {
    grid-template-columns: 1fr 1fr;
  }
}

/* Mobile Media Query */
@media (max-width: 600px) {
  .grid-container {
    grid-template-columns: 1fr;
  }
}
