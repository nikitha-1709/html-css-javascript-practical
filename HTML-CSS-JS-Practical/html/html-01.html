Create a basic HTML webpage using headings, paragraphs, and line breaks

Description: Demonstrates structural hierarchy using heading tags (h1 to h6), paragraph elements (p), horizontal rules (hr), and line breaks (br).

Working Implementation & Visible Output

Heading 1: Computer Science Department

This is an introductory paragraph describing the academic department. Welcome to the official practical session.
Line breaks allow splitting sentences onto a new line without creating a separate paragraph block.

Heading 2: Core Academic Disciplines

Students study data structures, algorithms, computer networks, and modern web application development.

Heading 3: Web Technologies Lab

Heading 4: HTML5 & Semantic Web

Heading 5: Sub-topic Configuration
Heading 6: Micro Footnote Tag

Source Code

html-01.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Basic HTML Page</title>
</head>
<body>
  <h1>Heading 1: Computer Science Department</h1>
  <p>This is an introductory paragraph describing the academic department.<br>
  Line breaks allow splitting sentences onto a new line.</p>
  <hr>
  <h2>Heading 2: Core Academic Disciplines</h2>
  <p>Students study data structures, algorithms, and web development.</p>
  <h3>Heading 3: Web Technologies Lab</h3>
  <h4>Heading 4: HTML5 & Semantic Web</h4>
  <h5>Heading 5: Sub-topic Configuration</h5>
  <h6>Heading 6: Micro Footnote Tag</h6>
</body>
</html>
