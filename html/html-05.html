Create a student registration form using HTML form elements

Description: Demonstrates comprehensive HTML form controls: text, email, radio buttons, checkboxes, select dropdowns, textareas, and submit/reset buttons.

Working Implementation & Visible Output

Source Code

html-05.html 
<form action="/submit-registration" method="POST">
  <label for="name">Full Name:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email Address:</label>
  <input type="email" id="email" name="email" required>

  <label>Gender:</label>
  <input type="radio" name="gender" value="male"> Male
  <input type="radio" name="gender" value="female"> Female

  <label>Interests:</label>
  <input type="checkbox" name="interest" value="web"> Web Dev
  <input type="checkbox" name="interest" value="ai"> AI

  <label for="dept">Department:</label>
  <select id="dept" name="dept">
    <option value="cse">Computer Science</option>
    <option value="ece">Electronics</option>
  </select>

  <label for="address">Address:</label>
  <textarea id="address" name="address"></textarea>

  <input type="submit" value="Register">
  <input type="reset" value="Reset">
</form>
