Create a webpage using HTML5 input types such as email, date, number, and password

Description: Demonstrates native HTML5 form inputs with browser-level validation: email, date, number, password, range, color, tel, and search.

Working Implementation & Visible Output

Value: 65%
Fill fields and submit to test native HTML5 validation constraints.

Source Code

html-09.html 
<form>
  <!-- Email -->
  <input type="email" placeholder="student@college.edu" required>

  <!-- Date -->
  <input type="date" name="dob">

  <!-- Number -->
  <input type="number" min="1" max="100" step="1">

  <!-- Password -->
  <input type="password" minlength="8" required>

  <!-- Range -->
  <input type="range" min="0" max="100">

  <!-- Color -->
  <input type="color">
</form>
