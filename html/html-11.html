Create a webpage with internal and external CSS styling

Description: Demonstrates the cascade and implementation differences between inline styles, internal style tags (<style>), and external stylesheet link (<link rel='stylesheet'>).

Working Implementation & Visible Output

1. External CSS Rules (Applied from ../assets/common.css)

Global font-family, body background, .lab-container layout, and CSS variables.

2. Internal <style> Block Rules

Configured specifically within the head section of this document for scoped layouts.

3. Inline Style Attributes (Highest Cascading Precedence)

This text has inline style="color: #7f1d1d; font-weight:600;" which directly overrides external or internal rules.

Source Code

html-11.html 
<!-- 1. External CSS Link -->
<link rel="stylesheet" href="../assets/common.css">

<!-- 2. Internal CSS -->
<style>
  .card-internal {
    background-color: #fef3c7;
    border: 1px solid #fde047;
    padding: 16px;
  }
</style>

<!-- 3. Inline CSS -->
<div class="card-internal" style="color: #991b1b; font-weight: bold;">
  Inline styling applied directly onto the element.
</div>
